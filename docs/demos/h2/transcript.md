# H2 narrated walkthrough

Narration: Microsoft Zira (synthetic voice).

## 00:00:00 — Recognize a saved piece

H two adds a photograph to a saved item. This walkthrough uses a synthetic gemstone illustration, so no personal photograph or embedded location information is involved. The item is already saved with its name and storage location.

## 00:00:17 — Prepare on your device

Choose an image using the native picker. The browser resizes this camera sized image before anything is uploaded. You can inspect the preview and the prepared file size. Embedded metadata is removed, but anything visible in the photograph remains visible. Upload only when you are ready.

## 00:00:38 — Return to the photograph

The photograph is now saved. Reloading the page brings it back from private storage. The gallery and compact list show the whole image without cropping. Another signed in browser session can open the same saved photograph.

## 00:00:54 — Replace safely

Choose a replacement and review it beside the saved photograph. The current image stays available while the replacement is prepared. Here we deliberately lose the response after the server saves. Retry upload safely resolves the same request and confirms the replacement.

## 00:01:13 — At the workbench

On a phone, the same photograph and actions remain available. Light and Dark appearances use a neutral background around the whole image. You can recognize the piece and read its storage location without returning to a desktop.

## 00:01:29 — Remove only the photograph

Removing a photograph asks for confirmation. You can keep it, or confirm removal. The item, its name, notes, and storage location remain in the collection. H two supports one photograph per saved item, with explicit replacement and removal.
