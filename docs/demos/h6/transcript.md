# H6 archive recovery walkthrough transcript

The Archive is separate from the active collection. Records set aside here keep their saved details and photographs.

Search finds words in names, notes, and locations throughout the archive, including records beyond the first page.

This is the original record and photograph. Archived details are read only. Restore to collection makes them editable again.

Restoration asks for explicit confirmation. Cancel makes no change and returns keyboard focus to the restore button.

Here we deliberately lose the response after the server saves. The screen reports uncertainty and keeps the original request across appearance changes.

Retry uses the same checked version. The saved record is already active, so Workbench reloads its current state without claiming this retry restored it.

The archive search is refreshed and no longer includes the restored record. Its search words and List preference remain available.

After reload, the same identifier, notes, location, and photograph are back in the active collection. These automated checks do not establish collector usability.
