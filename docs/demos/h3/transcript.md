# H3 narrated walkthrough

Narration: Microsoft Zira (synthetic voice).

## 00:00:00 — Find a remembered piece

Workbench now searches the entire collection by name, notes, or storage location. This demonstration uses synthetic records in a disposable database.

## 00:00:12 — Search remembered words

Type a remembered phrase and press Search. Matching ignores letter case and treats punctuation literally. Here, September fair appears in the notes, so the sapphire is found even though its name is different.

## 00:00:27 — Return to the same result

On a phone, choose the compact list and open the sapphire. Its location is right here. Returning to the collection preserves the query, list view, and selected result. Changing appearance keeps the task intact.

## 00:00:44 — Recover from a failed search

A simulated connection failure shows an error, not an empty collection. Retry repeats the submitted query and retrieves the matching piece.

## 00:00:54 — Clear without changing records

A phrase with no matches has its own message. Clear returns to the collection without changing any records. Search state stays in this signed-in app and resets on a full reload or sign-out.
