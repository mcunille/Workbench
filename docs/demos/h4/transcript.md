# H4 narrated walkthrough

Narration: Microsoft Zira (synthetic voice).

## 00:00:00 — Keep a record accurate

Workbench lets you correct an item's name, notes, and location while keeping its permanent identity. This walkthrough uses a synthetic item and a disposable database.

## 00:00:12 — Cancel a correction

Open Edit details and change the name. Cancel returns to the saved record without changing it.

## 00:00:20 — Keep the draft through a failed save

On a phone, change the location. This save encounters a simulated server failure. Your text remains available, even when appearance changes. Retry safely submits the same checked request.

## 00:00:36 — Protect another session's changes

Two independently signed-in sessions opened the same record. The other session now saves a new name. Saving this older draft reports a conflict and preserves the draft for comparison.

## 00:00:49 — Reconcile explicitly

Review my edits starts from the latest saved values. Keep the new name, copy the intended notes from the preserved draft, and save. The newer record is never silently overwritten.

## 00:01:04 — Find the updated record

Return to the collection and search the updated notes. The same item appears with its corrected name and location. Reloading confirms the changes are stored.
