# Navigation design ideas

[Open the crystal dock prototype](workbench-tanzanite-nav.html) locally in a browser.
It is a standalone HTML file with inline icons, styles, and interactions; no package,
host widget, remote font, or network request is required. The icon outlines replace the
original host-provided icons so the saved concept remains usable outside the conversation.

This preserves the subtle charcoal/tanzanite exploration before desktop refinement.
Try Search (sample filtering), Administration, User, Escape, and Appearance. Sample
items and QA identity are fictional. Actions report a mock result and do not save data.
The integrated search and morphing panels are exploratory; this file is not an app route
or a supported desktop navigation mode. The selected mobile pill uses existing destinations
without search. See the [accepted decision](../specs/2026-09-09-refined-navigation.md)
and [living guidance](../../DESIGN.md#authenticated-navigation).

Screenshots are kept outside the repository and Git history under the repository's media
policy. The delivery PR may embed an attachment after capture; the interactive file remains
the portable visual reference if attachment support is unavailable.
