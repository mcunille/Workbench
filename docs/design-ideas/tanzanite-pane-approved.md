# Tanzanite pane — accepted material baseline

Saved during the glass-material exploration. Dark mode only.

The companion `tanzanite-pane-approved.css` preserves the full navigation stylesheet
at palette approval, before Pearl experimentation. It is a reference snapshot, not
an additional application stylesheet.

Approved preview vividness: **85%**. With the original slider mapping this means:
- Interior reflection opacity: `0.85`.
- Edge opacity: `1`.
- Edge brightness: `1.5066176471`.
- Edge saturation: `1.3117647059`.

Keep the photo-inspired indigo, sapphire blue, and cool periwinkle palette.
No pink accents, white glints, or repeated rays. Use shallow edge-color bleed with
three faint angled reflections. Preserve the existing pane geometry and controls.
Pearl is a separate light-mode exploration and must not alter this dark baseline.
